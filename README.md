## Customer Sales & Churn Analysis

## Project Overview

This project analyzes customer sales and churn using python
The analysis focuses on customer spending,subscription type,tenure,support calls, and churn behaviour
The main goal is to identify customer patterns and generate useful businees insights from the data

## Tools and Technologies

-Python
-Pandas
Matplotlib
-Seaborn
-Vs Code

## Analysis Performed

-Checked customer data for missing values and duplicate records
-Calculated total customers and churn rate
-Analyzed customer by city
-Analyzed customer by subscription type
-Calculated average spending
-Compared monthly spending  by churn status
-Compared customers tenure by churn status
-Analyzed support call by churn status
-Created chart to visualize customer and churn patterns
-Generated final business insights

## Keys Insights

-Total customers analyzed: 5
-Churned customers: 3
-Overall churn rate: 60%
-Average monthly spend: 1240
-Customer churn ompared across subscription types
-Monthly spending,tenure,and support calls were analyzed based on churn status
